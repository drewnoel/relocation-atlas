# Layer catalog

Each layer is a CSV in `layers/`. `kind` decides which Top 10 a place competes for; `tag` links it to an interest.

| Group | Layer examples | kind | tag |
|---|---|---|---|
| Getting around | Transit stations, bike share docks | daily | transit / outdoors |
| Coffee | Specialty cafés, walk-up windows | daily | coffee |
| Fitness | Gyms, studios, pools, recovery | daily | fitness |
| Groceries | Supermarkets, markets, pharmacies | daily | groceries |
| Services | Laundry, tailor, barber, repair | daily | services |
| Health & errands | Urgent care, primary care, post office, hardware | daily | health |
| Outdoors | Parks, run routes, running clubs | daily | outdoors |
| Work & study | Libraries, day-pass coworking, laptop cafés | daily | cowork |
| Music | Listening bars, live music, dance nights | weekly | music |
| Views | Rooftops, terraces, public overlooks | weekly | views |
| Drinks | Cocktail bars or zero-proof bars | weekly | nightlife / zero-proof |
| Culture & dining | Museums, galleries, standout restaurants | weekly | culture |
| Social | Recurring meetups, clubs, community groups | weekly | social |
| Career | Notable employers, coworking hubs, meetup venues | weekly | career |

Pick the groups the person rated 1 or higher. Size: 10–30 rows per layer is plenty; 50 for a ranked "best of" list.
Link out instead of copying when a maintained public guide exists (restaurant rankings, landmark registers).
